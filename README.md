# Практическая работа № 3
## «Адаптивная виртуальная экскурсия по объекту»

### Тема и выбор объекта
Вы создаёте страницу виртуальной экскурсии. Можно использовать тему **русской усадьбы** 
(изображения уже есть в папке `/images/` этого репозитория) или выбрать свой объект:
белорусскую усадьбу, университет, музей, парк, архитектурный комплекс.

### Уровни сложности
- **BASE** — обязательный минимум (реалистично за один вечер)
- **JUNIOR** — галерея + вторая страница + DevTools Network
- **PRO** — карта ссылок + Lighthouse Accessibility + стресс-тест

_(полное описание требований — в файле `Практическая работаNo 3.pdf`) или в соответствующем канале в Slack_

### Как сдать (Pull Request)
1. Сделайте Fork этого репозитория к себе
2. Создайте ветку `homework-03`
3. Работайте в папке `homework-03/` — не трогайте другие папки
4. Сделайте ** 4–5 осмысленных коммитов** (меньше нельзя, больше можно):
   - `feat: add semantic page structure`
   - `feat: add picture and image formats`
   - `feat: add srcset sizes and gallery`
   - `feat: add second page and links` _(JUNIOR и PRO)_
   - `fix: validate HTML and accessibility`
5. Push → Create Pull Request → заполните шаблон → приложите скриншоты

**Дедлайн:** до 22:00 [21.09.2026]

### Жёсткий фильтр — работа не принимается если:
- нет Pull Request из ветки `homework-03` (ссылки на репозиторий не принимаются)
- есть `<div>` вместо семантических тегов (на BASE и JUNIOR)
- нет скриншота W3C Validator с 0 ошибок
- меньше 4 коммитов
