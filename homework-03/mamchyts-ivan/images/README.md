## Как получить изображения

### Вариант 1 — Тема русской усадьбы (самый простой)
Изображения уже есть в папке `/images/` этого репозитория. Скопируйте нужные и переименуйте по таблице выше.

### Вариант 2 — Свободные фото из интернета (CC0)
- **Unsplash** — [unsplash.com](https://unsplash.com) — бесплатно, без атрибуции
- **Pexels** — [pexels.com](https://pexels.com) — бесплатно, без атрибуции
- **Wikimedia Commons** — [commons.wikimedia.org](https://commons.wikimedia.org) — проверяйте лицензию CC0 или CC-BY

### Вариант 3 — Собственные фотографии
Подходят любые ваши фото подходящей тематики.

## Как создать WebP версии

### В Windows (бесплатно)
Установите **IrfanView** → File → Save As → выберите формат WebP.

### Онлайн (быстро)
- [squoosh.app](https://squoosh.app) — конвертация и сжатие прямо в браузере
- [convertio.co](https://convertio.co/jpg-webp/) — конвертация JPG → WebP

### Как сделать мобильный кроп
Откройте изображение в любом редакторе (Paint, Photoshop, Figma, GIMP) → обрежьте вертикально (портретный формат, акцент на главном объекте) → сохраните как WebP.

## Требования к изображениям

- ✅ Понятные имена файлов (как в таблице выше)
- ✅ Относительные пути: `images/hero.jpg`, не `/home/user/...`
- ✅ Корректный `alt` на каждом `<img>`
- ✅ Атрибуты `width` и `height` на каждом `<img>`
- ✅ Легально получены (CC0, собственные, CC-BY с атрибуцией)
- ✅ Соответствуют теме страницы
